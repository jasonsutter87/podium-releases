# Podium for Mac

Downloads of [Podium](https://podium-elearning.netlify.app/), the eLearning authoring tool. This repository holds releases only; Podium's source isn't here.

**[Download the latest Podium.dmg](https://github.com/jasonsutter87/podium-releases/releases/latest/download/Podium.dmg)**

- For Macs with Apple silicon, macOS 12 or later.
- Open the DMG and drag Podium to Applications.
- The first time you open it, macOS says it can't verify the developer. Open **System Settings → Privacy & Security** and click **Open Anyway**. (A notarised build is coming.)
